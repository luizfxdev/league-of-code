# Operadores em Go ? LoL Edition

## Exemplo Prático: Game Server com Validação de Combate

```go
package game

import (
    "fmt"
    "time"
)

// Struct = Campeão (instância com stats próprios)
type Champion struct {
    Nome               string        // "Garen", "Lux", "Ahri"
    HealthAtual        float64       // HP (varia)
    ManaAtual          float64       // Mana (varia)
    AttackDamage       float64       // AD (aumenta com itens)
    EstaVivo           bool          // Estado: alive?
    EstaStunado        bool          // CC aplicado?
    UltimaProntaEm     time.Time     // Cooldown da ulti
}

// Constante = Buff global (imutável, regra do jogo)
const (
    VelocidadeMovimentoBase = 330.0
    DanoMinionBase          = 5.0
    ManaRegeneracaoBase     = 5.0
    NivelUltiDestravaEm     = 6
)

// Variável global (pode mudar em runtime, buff dinâmico)
var (
    DanoMaximoParaCombo = 500.0  // Buff dinâmico ? pode ser alterado em hotfix
    HealthRegenBase     = 7.5    // Regen global
)

// Métodos (funções que pertencem a um tipo)
func (c *Champion) PodeAtacarAgora(alvo *Champion) bool {
    // Guard 1: campeão existe?
    if c == nil {
        return false  // Personagem não foi spawnado
    }
    
    // Guard 2: está vivo?
    if !c.EstaVivo {
        return false  // Morto não ataca
    }
    
    // Guard 3: tem mana?
    if c.ManaAtual <= 0 {
        return false  // Broke de mana ? não pode cashar habilidade
    }
    
    // Guard 4: alvo existe e está vivo?
    if alvo == nil || !alvo.EstaVivo {
        return false  // Alvo morto ou null
    }
    
    // Guard 5: está CC'd (stunado)?
    if c.EstaStunado {
        return false  // CC aplicado, sem permissão de agir
    }
    
    return true  // Win condition ? pode atacar!
}

func (c *Champion) CalcularDanoFinal() float64 {
    // Usa constante global (DanoMinionBase é buff do jogo)
    // Usa variável global (HealthRegenBase pode mudar com patch)
    return c.AttackDamage + DanoMinionBase
}

// Função de validação ? Go usa múltiplos retornos: (valor, erro)
func ValidarEngajamento(c *Champion, alvo *Champion, temVantagem bool) error {
    // Guard clauses: rejeição rápida
    
    if c == nil {
        return fmt.Errorf("campeão attacker é nil")  // Null pointer
    }
    
    if !c.PodeAtacarAgora(alvo) {
        return fmt.Errorf("campeão %s não pode atacar agora", c.Nome)
    }
    
    if !temVantagem {
        return fmt.Errorf("sem vantagem numérica")
    }
    
    // Sem erro = sucesso
    return nil
}

// Main
func main() {
    garen := &Champion{
        Nome:           "Garen",
        HealthAtual:    590,
        ManaAtual:      0,
        AttackDamage:   80,
        EstaVivo:       true,
        EstaStunado:    false,
        UltimaProntaEm: time.Now(),
    }
    
    lux := &Champion{
        Nome:           "Lux",
        HealthAtual:    520,
        ManaAtual:      380,
        AttackDamage:   50,
        EstaVivo:       true,
        EstaStunado:    false,
        UltimaProntaEm: time.Now(),
    }
    
    // Validar engajamento
    err := ValidarEngajamento(garen, lux, true)
    if err != nil {
        fmt.Println("Erro:", err)
        return  // Early exit
    }
    
    fmt.Println("Engajamento validado!")
    dano := garen.CalcularDanoFinal()
    fmt.Printf("Dano de %s: %.2f\n", garen.Nome, dano)
}
```

## Operadores Comparativos

| Operador | Significado | LoL | Exemplo |
|----------|------------|-----|---------|
| `==` | Igual a | Mesmo nível | `if status == "ATIVO"` |
| `!=` | Diferente de | Inimigos | `if kmAtual != 0` |
| `>` | Maior que | Mais HP | `if kmTotal > limite` |
| `<` | Menor que | Menos ouro | `if kmAtual < 100_000` |
| `>=` | Maior ou igual | HP >= necessário | `if tempo >= 30` |
| `<=` | Menor ou igual | Mana <= cap | `if nivel <= 3` |

### Exemplos Práticos:

```go
nivel := 5
experiencia := 3200

// Igualdade com strings
if status == "ATIVO" {
    fmt.Println("Pode processar")  // ?
}

// Desigualdade
if nivel != 1 {
    fmt.Println("Não é level 1")  // ?
}

// Maior/menor com números
if experiencia > 3000 {
    fmt.Println("Quase level up")  // ?
}

// Comparação de pointers (cuidado!)
var v1 *Veiculo = &Veiculo{Placa: "ABC"}
var v2 *Veiculo = &Veiculo{Placa: "ABC"}

if v1 == v2 {
    fmt.Println("Mesmo objeto")  // ? FALSE (endereços diferentes)
}

if v1.Placa == v2.Placa {
    fmt.Println("Mesma placa")   // ? TRUE (valores iguais)
}
```

## Operadores Lógicos

| Operador | Significado | LoL | Quando Usar |
|----------|------------|-----|------------|
| `&&` | E (AND) | **Ambos** têm que estar certos | Validações em série |
| `\|\|` | OU (OR) | **Um ou outro** vale | Alternativas |
| `!` | NÃO (NOT) | Inverte condição | Negar um estado |

### AND (`&&`) ? Validação Rigorosa

```go
podeAtacar := temMana && temVida && !emCC && temAlvo
//            ^^^^^^^^  ^^^^^^^^  ^^^^^  ^^^^^^^
//            Tudo tem que ser TRUE

if podeAtacar {
    ativarUlt()  // Só executa se TUDO passar
}
```

**Analogia:** Você precisa estar vivo **E** ter mana **E** não estar CC **E** ter alvo visível.

**Short-circuit em Go:**
```go
veiculo := &Veiculo{...}

// Para na primeira condição false
if veiculo != nil && veiculo.PodeUsarEmOS(10_000) && veiculo.ValorCustodia > 0 {
    fmt.Println("Pode executar")
}

// Se veiculo for nil, não chama PodeUsarEmOS (safe!)
```

### OR (`||`) ? Alternativas Aceitáveis

```go
statusPermitido := 
    status == "ATIVA" ||
    status == "PENDENTE" ||
    status == "EMERGENCIA"

if statusPermitido {
    processarOS()  // Executa se alguma condição for true
}
```

**Analogia:** Você ganha se destrói inibidor **OU** mata barão **OU** destrói nexo.

```go
// Determinar custo com alternativas
var custoBruto float64
if tipoVeiculo == "PESADO" || tipoVeiculo == "ESPECIAL" {
    custoBruto = valor * 1.5  // Taxa aumentada
} else {
    custoBruto = valor * 1.0  // Taxa normal
}
```

### NOT (`!`) ? Negação

```go
podeUsar := !emManutencao  // Inverte: true ? false, false ? true

if !temProblema {
    fmt.Println("Está tudo bem")  // Executa se temProblema for FALSE
}
```

**Analogia:** É o oposto. Se Stun está ativo, `!stun` é false (você pode se mexer).

## Structs, Campos e Variáveis Globais ? LoL Mindset

### Structs = Campeões Únicos

```go
type Veiculo struct {
    // Cada instância é um campeão diferente
    Placa         string      // Nome único (SummName)
    KmAtual       int         // HP desta instância
    KmMilhao      int         // Bonus AD deste champ
    ValorCustodia float64     // Armor
}

v1 := &Veiculo{Placa: "ABC1234", KmAtual: 100_000, KmMilhao: 1}
v2 := &Veiculo{Placa: "XYZ9876", KmAtual: 250_000, KmMilhao: 2}

// v1 e v2 são instâncias DIFERENTES
// cada uma tem seus próprios stats
fmt.Println(v1.KmAtual)  // 100_000
fmt.Println(v2.KmAtual)  // 250_000 (diferente!)
```

### Campos = Stats do Campeão

```go
type Veiculo struct {
    Placa           string    // Identificador único
    KmAtual         int       // Health
    ValorCustodia   float64   // Armor
    EmManutencao    bool      // Flag: true/false
}

// Cada Veiculo tem stats INDEPENDENTES
v1.KmAtual = 150_000
v2.KmAtual = 200_000

// v1 != v2, mesmo que sejam ambos Veiculo
```

### Constantes = Buff Imutável (Global)

```go
// Constante = Não pode mudar durante execução
const (
    KmLimiteManutencao = 50_000      // Todos os veículos respeitam
    TaxaOperacao       = 0.15        // Taxa fixa
    StatusAtivo        = "ATIVO"     // Enumeração
)

// Tentar mudar gera erro em compilação
// KmLimiteManutencao = 60_000  // ? Compile error!

// Usar constante
if v.KmAtual > KmLimiteManutencao {
    fmt.Println("Precisa manutenção")  // Usa valor global
}
```

### Variáveis Globais = Buff Dinâmico

```go
// Variável global = pode mudar, afeta TUDO
var (
    KmMaximoParaOS     = 50_000
    TaxaProcessamento  = 0.12
)

// Pode alterar em runtime
func AjustarBuffGlobal() {
    KmMaximoParaOS = 60_000  // Alterou para TODOS
}

// Qualquer função vê a nova valor
func ValidarOS(veiculo *Veiculo, km int) bool {
    if km > KmMaximoParaOS {  // Usa valor global
        return false
    }
    return true
}
```

**Analogia:**
- **Campo:** Garen tem 100 HP, Darius tem 120 HP (diferentes)
- **Constante:** Todos têm o mesmo cd de Flash (5 min) ? imutável
- **Variável global:** Buff dinâmico que muda para TODO mundo

## Ponteiros (`*`) ? Referência vs Cópia

```go
// Sem ponteiro: cópia (alterações locais)
func AumentarKmCopia(v Veiculo) {
    v.KmAtual += 10_000  // Altera CÓPIA, não original
}

v := Veiculo{KmAtual: 100_000}
AumentarKmCopia(v)
fmt.Println(v.KmAtual)  // 100_000 (não mudou!)

// Com ponteiro: referência (alterações globais)
func AumentarKmReferencia(v *Veiculo) {
    v.KmAtual += 10_000  // Altera ORIGINAL
}

v := &Veiculo{KmAtual: 100_000}
AumentarKmReferencia(v)
fmt.Println(v.KmAtual)  // 110_000 (mudou!)
```

**Analogia:** Ponteiro é como dar permissão ao SM para mexer no seu código. Sem ponteiro, ele vê a cópia.

## Tratamento de Erro (Multiple Return)

```go
// Go usa erro como valor, não exceção
func ProcessarOS(veiculoId int, kmRequisicao int) (string, error) {
    v, err := BuscarVeiculo(veiculoId)
    
    // Guard: erro em cascata
    if err != nil {
        return "", fmt.Errorf("erro ao buscar veículo: %w", err)
    }
    
    if !v.PodeUsarEmOS(kmRequisicao) {
        return "", fmt.Errorf("veículo não pode executar OS")
    }
    
    // Sucesso
    osId := CriarOS(v, kmRequisicao)
    return osId, nil  // nil = sem erro
}

// Usar
osId, err := ProcessarOS(123, 10_000)
if err != nil {
    fmt.Println("Erro:", err)
    return  // Early exit
}

fmt.Println("OS criada:", osId)
```

**Analogia:** Go não lança exception, retorna erro como valor. Se não verificar, pode continuar com valor inválido ? é responsabilidade sua.

## Combinando Operadores ? Lógica Complexa

```go
type ValidacaoOS struct {
    VeiculoOK      bool
    KmOK           bool
    StatusOK       bool
    SistemaOK      bool
}

func ValidarOSCompleto(v *Veiculo, km int, status string) ValidacaoOS {
    return ValidacaoOS{
        VeiculoOK:  v != nil && !v.EmManutencao,
        KmOK:       km > 0 && km <= KmMaximoParaOS,
        StatusOK:   status == StatusAtivo || status == StatusInativo,
        SistemaOK:  VerificarSistema(),
    }
}

func ExecutarOS(v *Veiculo, km int, status string) error {
    validacao := ValidarOSCompleto(v, km, status)
    
    // AND lógico: tudo tem que passar
    if !validacao.VeiculoOK || !validacao.KmOK || !validacao.StatusOK || !validacao.SistemaOK {
        return fmt.Errorf("validação falhou")
    }
    
    // Seguro para executar
    return CriarOSSeguro(v, km)
}
```

var flags int = FlagAtivo | FlagPrioritario  // 0101

**Não recomendado para código novo** ? use bools ou enums em vez disso.

## Boas Práticas ? Guard Clauses em Go

```go
// ? Ruim: Aninhamento profundo
func ProcessarVeiculoRuim(v *Veiculo, km int, status string) error {
    if v != nil {
        if !v.EmManutencao {
            if km > 0 {
                if km <= KmMaximoParaOS {
                    if status == StatusAtivo {
                        // 5 níveis deep ? difficults
                        return CriarOS(v, km)
                    }
                }
            }
        }
    }
    return fmt.Errorf("falha na validação")
}

// ? Bom: Guard clauses (rejeição rápida)
func ProcessarVeiculoBom(v *Veiculo, km int, status string) error {
    // Validações rápidas com return imediato
    if v == nil {
        return fmt.Errorf("veículo é nil")
    }
    
    if v.EmManutencao {
        return fmt.Errorf("veículo está em manutenção")
    }
    
    if km <= 0 || km > KmMaximoParaOS {
        return fmt.Errorf("km inválido: %d", km)
    }
    
    if status != StatusAtivo {
        return fmt.Errorf("status inválido: %s", status)
    }
    
    // Aqui é seguro, tudo passou
    return CriarOS(v, km)
}
```

**Analogia:** Guard clause é recuar se a lane não tem visão. Não entra no jogo até ter segurança.

## Precedência de Operadores em Go

```go
// && tem precedência sobre ||
resultado := true || false && false
//           ^^^^   ^^^^^ ^^ ^^^^^
//                  Isso avalia PRIMEIRO (false && false = false)
// Resultado: true || false = true

// Equivalente a:
resultado = true || (false && false)  // true

// Se quer outro comportamento, use parênteses:
outro := (true || false) && false      // false
```

## Type Assertion ? Verifica Tipo (Go)

```go
// Interface vazia (qualquer tipo)
var valor interface{} = "texto"

// Type assertion (verifica tipo)
str, ok := valor.(string)
if ok {
    fmt.Println("É string:", str)  // ?
} else {
    fmt.Println("Não é string")
}

// Type switch (múltiplos tipos)
switch v := valor.(type) {
case string:
    fmt.Println("String:", v)
case int:
    fmt.Println("Int:", v)
case *Veiculo:
    fmt.Println("Veículo:", v.Placa)
default:
    fmt.Println("Tipo desconhecido")
}
```

## Resumo: When to Use What em Go

| Situação | Operador | Exemplo |
|----------|----------|---------|
| Validação obrigatória | `&&` | `if tem && valido && ativo` |
| Alternativas aceitáveis | `\|\|` | `if status == "A" \|\| status == "B"` |
| Inverter condição | `!` | `if !emManutencao` |
| Teste de igualdade | `==` | `if status == "ATIVO"` |
| Comparação | `>`, `<`, `>=`, `<=` | `if km > limite` |
| Verificar nil | `== nil` ou `!= nil` | `if v != nil` |
| Tratamento de erro | `if err != nil` | Guard clause padrão |
| Múltiplos valores | Multiple return | `v, err := Buscar()` |
| Type check | Type assertion | `str, ok := val.(string)` |

## Constants vs Vars ? Decisão

| Situação | Use | Exemplo |
|----------|-----|---------|
| Valor fixo, imutável | Const | `const KmLimiteManutencao = 50_000` |
| Valor pode mudar durante execução | Var | `var KmMaximoParaOS = 50_000` |
| Private (sem maiúscula) | Const/Var | `const kmInterno = 100` |
| Public (maiúscula) | Const/Var | `const KmLimitePublico = 100` |

**Go style:** Prefer const quando possível (sem side effects, mais seguro).
